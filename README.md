# 破蛹 EMERGE

設計者：**楊亞璇**（實踐大學 服裝設計系）
凱達格蘭族服裝設計作品的 3D 展示網站。
公開網址：https://fr3636k.github.io/ya-hsuan/

## 設計理念

> 我的設計理念是關於，凱達格蘭女巫一族帶給我對自我角色的反思與進化。

**女巫＝知識與權力**
女巫一詞在凱達格蘭族象徵知識與權力，不同於典型的女巫型態，更像一種對認知的運用。這份力量是一種突破、一種微妙的蛻變；作品想傳達的，是女性蛻變、擁有力量的過程。

**她是誰**
一個被世俗框架住的女性角色，在掙扎、自我搏鬥中成長；一個不被認同的女性角色，在探索、破壞原有的界線下壯大。

**「破」的力量**
破是這件作品要傳達的情緒：

- 破會給空間延展性
- 破會給幻想多點氛圍
- 破會給話語間多點挽留
- 破會讓女性蛻變成理想的樣子

**燈光：從北投的煙霧開始**
燈光的起點是北投瀰漫的煙霧。煙霧是一種不確定性，是想被看到、又不想被看到。

- **呼吸**（一亮一暗）：生生不息；向自我以外的人表達意念，傳遞「我在這裡發亮著」。
- **快速換氣**（閃）：渴望突破，正在突破。

## 理念如何落在服裝上

| 服裝 | 對應的理念 |
|---|---|
| 上半身的繭（骨架撐起壓皺的珠光布，光從布瓣間透出） | 世俗的框架；光透出來，是她在裡面發亮著 |
| 帽沿壓低、臉藏在繭的開口裡 | 想被看到，又不想被看到 |
| 白光的亮、暗、閃 | 呼吸與快速換氣 |
| 繭裡沒有衣服、腰間微露 | 繭是外殼，不是衣服；裡面是她自己 |
| 針織魚尾裙緊貼雙腿，腳邊以斜角張開 | 束縛與張力；破給空間延展性 |
| 雙手抓住繭的邊緣 | 探索、破壞原有的界線 |

## 網頁敘事

1. **開場**：全暗，只有繭裡的光在呼吸 → 光漸強、閃一下 → 外面的燈亮起，她出現。
2. **01 破蛹而出**：全身。被框架住的她在掙扎中成長。
3. **02 帽沿與臉**：臉部特寫。想被看到，又不想被看到。
4. **03 煙霧與呼吸**：繞到背面看整顆發光的繭，說明燈光節奏的意義。
5. **04 針織魚尾**：下擺特寫。
6. **結尾**：鏡頭回到她面前，雙手從繭裡伸出抓住外殼（AI 生成影片，第一格與 3D 畫面對齊），最後是設計者的話與署名。

原作的粉紅 LED 在網頁中改為白光。

## 操作方式

- 手機：手指向上滑動，一段一段往下看；每段會停留一下再放行。
- 電腦：滾動滑鼠滾輪，或按方向鍵、空白鍵。
- 右側的圓點顯示目前在第幾段，點一下可以直接跳過去。
- 開場動畫播完前（約 3 秒）不能滑動，畫面下方會顯示「開場播放中」。

`viewer.html` 是自由旋轉檢視模型、切換燈光的頁面，入口只放在首頁最後一幕（署名下方的「進入 3D 檢視」），前面的章節不提供。

## 專案架構

這是一個**純靜態網站**：沒有後端、沒有前端框架、也沒有打包步驟。瀏覽器直接讀取 `dist/` 裡手寫的 HTML、CSS 與 JavaScript 模組（ES Modules），3D 畫面用 Three.js。

整個專案分成三層：

| 層 | 位置 | 做什麼 |
|---|---|---|
| 網站本體 | `dist/` | 實際發布的內容，推上 `main` 後原封不動發布到 GitHub Pages |
| 素材製作 | `scripts/` | 在本機把原始 3D 模型、AI 影片處理成網站用的檔案，結果寫進 `dist/models/`、`dist/media/` |
| 本機預覽 | `serve.mjs`、`start-preview.ps1` | 在電腦上開一個預覽用的小伺服器 |

```
dist/                    網站本體（就是發布的內容）
├─ index.html            首頁：捲動敘事
├─ viewer.html           3D 自由檢視頁
├─ css/style.css         兩個頁面共用的樣式
├─ js/                   自己寫的程式
│  ├─ story.js           首頁主程式：章節鏡頭、開場、結尾影片
│  ├─ viewer.js          檢視頁主程式：旋轉、視角、燈光控制
│  ├─ stage.js           兩頁共用：場景、燈光節奏、載入畫面
│  ├─ garment-glb.js     兩頁共用：載入模型、發光與布面效果
│  ├─ grip-seq.js        結尾影片的畫格播放
│  └─ model-config.js    模型路徑與效果參數
├─ vendor/               第三方程式（Three.js 與模型解碼器），不要手改
├─ models/               網站用的 3D 模型
└─ media/grip/           結尾影片的畫格
scripts/                 素材製作腳本（Python、Blender）
doc/                     設計理念原稿
.github/workflows/       自動發布設定
```

只留本機、不進版本庫的資料夾見文末。

## 維護

| 要改的 | 位置 |
|---|---|
| 章節文字、設計者署名 | `dist/index.html` |
| 字體大小、操作提示的樣式 | `dist/css/style.css` |
| 各章鏡頭、開場時間軸、章節圓點 | `dist/js/story.js` |
| 燈光節奏 | `dist/js/stage.js` 的 `RHYTHM` |
| 發光、燈籠、布面效果參數 | `dist/js/model-config.js` |
| 模型處理（V2 Tripo → 網頁用） | `scripts/process-model.py --tripo`、`scripts/draco-compress.py` |
| 快速載入用的預覽模型 | Blender `scripts/make-preview-src.py` → `npx gltfpack -i 輸入 -o dist/models/emerge-c-preview.glb -cc -si 0.015 -sa` |
| 結尾影片換新 | `python scripts/grip-frames.py <影片.mp4> --sharp-eyes` |

- 本機預覽：`node serve.mjs` → http://127.0.0.1:8788
- 發布：推上 `main` 後由 GitHub Actions 自動發布 `dist/`。提交規範見 `AGENTS.md`（`<type>(<scope>): <中文說明>`）。
- 只留本機、不上傳：參考照片 `data/`、歷次 3D 模型 `models/`（V1 TRELLIS、V2 Tripo，見其中的 README）、影片素材 `video-src/`。
