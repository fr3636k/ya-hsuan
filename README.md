# 破蛹 EMERGE

凱達格蘭族服裝設計作業的 3D 展示網站。
公開網址：https://fr3636k.github.io/ya-hsuan/

## 設計核心

**母系 · 破蛹而出**
凱達格蘭族是母系社會，女性是承接與延續的核心。服裝以「蛹」為形：女性被包覆、孕育，最後自己撐開外殼、走出來。破蛹不是被解放，而是她主動的選擇。

**蛹＝燈籠**
上半身是一顆前傾、往後延伸的繭，像花苞低頭。骨架撐起薄紗般的布面，布繃在骨架上只留輕微皺褶；光從背後的圓弧透出，骨架在光裡成為剪影。

**光＝呼吸**
原作的粉紅 LED 在網頁中全部改為白光，節奏是 **亮 → 暗 → 閃一下**：像呼吸，也像心跳，代表繭裡正在甦醒的生命。

**下半身＝束縛與張力**
針織魚尾裙緊貼身體、下擺展開成荷葉褶，與上方膨大的繭形成收與放的對比；腰間的束結是繭與身體的交界。

## 網頁敘事

1. **開場**：全暗，只有繭裡的光在呼吸 → 光漸強、閃一下 → 外面的燈亮起，她出現。
2. **章節**：滑動時鏡頭繞著她轉，依序看帽沿與臉、燈籠骨架、魚尾下擺；說明只留側邊小字。
3. **結尾**：鏡頭停在她面前，她的手從繭裡伸出，準備破殼而出（AI 生成影片，第一格與 3D 畫面對齊）。

另有 `viewer.html` 可自由旋轉檢視模型、切換燈光。

## 維護

| 要改的 | 位置 |
|---|---|
| 章節文字 | `dist/index.html` |
| 各章鏡頭、開場時間軸 | `dist/story.js` |
| 燈光節奏 | `dist/stage.js` 的 `RHYTHM` |
| 發光、燈籠、布面效果參數 | `dist/model-config.js` |
| 模型處理（Tripo → 網頁用） | `scripts/process-model.py --tripo`、`scripts/draco-compress.py` |
| 結尾影片換新 | `python scripts/grip-frames.py <影片.mp4> --sharp-eyes` |

- 本機預覽：`node serve.mjs` → http://127.0.0.1:8788
- 發布：推上 `main` 後由 GitHub Actions 自動發布 `dist/`。提交規範見 `AGENTS.md`（`<type>(<scope>): <中文說明>`）。
- 參考照片、AI 原始檔、影片素材（`data/`、`models-raw/` 等）只留本機，不上傳。
